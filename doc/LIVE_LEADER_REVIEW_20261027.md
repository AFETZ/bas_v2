## Замечания по приоритету

1. **Незакрытое требование: полнота параметров.** `scripts/product/capture_effective_config.py:44` прямо ограничивает экспорт наблюдёнными PARM.1388 имён не сверены с `PARAM_VALUE.param_count/param_index`; `LOG_DISARMED=0` ограничивает DataFlash до arming. Следующий шаг — штатный read-all с дозапросом пропусков и проверкой изменений через сеть, до/после измерительного окна. Старые 30 run остаются observed-only; новый снимок не доказывает их полноту задним числом. [MAVLink Parameter Protocol](https://mavlink.io/en/services/parameter.html).
2. **Непроверенный пользовательский путь.** Внешние команды и смена режима в полёте доказаны; полного ручного цикла именно по `make operator`→`make gcs` в изученных данных нет. Нужен один короткий запуск с выбором аппарата, взлётом, сменой высоты, LAND/disarm и записью консоли. GUI показать отдельным инженерным запуском при доступном display; его RTF нельзя заимствовать из headless-серии.
3. **Интерпретация физического времени.** `relay_experiment.py:542` создаёт новую цель каждые 20s при fault45s. Для последнего завершающего UAV среднее 21,3022s =14,9726s ожидания создания новой цели +0,9834s до её первого UART +5,3462s движения/удержания. Для fixed это 54,9688+7,3866+5,3593s. Это сценариозависимый исход; собственно восстановление приёма новой команды —3,9634s.
4. **Обобщение результатов ограничено.** Пять повторов одной миссии/фазы отказа и все переходы 1→4 не дают общей гарантии≤4s; худший наблюдаемый запас 18ms. Перебор 3125 bootstrap-resamples точен вычислительно, но не доказывает точность 95% покрытия приn=5. Сохранить слово «разведочный» и все парные точки.
5. **Смысл координатора.** НПУ рассчитывает пять индивидуальных целей (`relay_experiment.py:545`), master пересылает адресованный payload (`service.py:214`). Определить координатор как назначаемый ретранслятор команд; самостоятельное бортовое планирование групповой миссии не исследовалось.
6. **Граница отказов.** Удержание подтверждено при RF-изоляции с живыми sidecar/runtime. Исчезновение native watchdog завершает сервис до lease/BRAKE (`service.py:283,92,185,658`); наблюдаемый `FS_GCS_ENABLE=0`. Гарантия поведения при падении процесса/хоста отсутствует и для нынешней статьи не требуется.
7. **Устаревшие стартовые инструкции.** `AGENTS.md:14,23,31` и `doc/DEV_ENVIRONMENT.md:4` ещё описывают состояние до реализации. Перед делегированием следующего этапа согласовать их с RESULTS/STATUS, сохранив ограничения достоверности. Worker-ветки имеют разные HEAD; не переносить их целиком поверх интеграции и не сбрасывать чужие изменения.
