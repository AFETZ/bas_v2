# Customer Handoff Scaffold

This directory documents the customer bundle generated by:

```bash
./network/scripts/collect_artifacts.sh runs/<run_id>
```

The generated bundle is written under `artifacts/customer_delivery_<run_id>/`
and archived as `artifacts/customer_delivery_<run_id>.tar.gz`.

Customer-ready status is controlled by validation evidence, not by bundle
creation. The bundle is customer-ready only when:

- `runs/<run_id>/metrics/summary.json` has `p0_passed: true`.
- `runs/<run_id>/metrics/summary.json` has `customer_ready: true`.
- `runs/<run_id>/validation_report.md` records every P0 gate as passed.

If any P0 evidence is missing, the bundle remains a handoff package for current
engineering state and must be read with `known_limitations.md`.
