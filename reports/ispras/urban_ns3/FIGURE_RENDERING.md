# Canonical urban figures

Renderer implementation only; **no new measured figures were generated by the
metrics worker during the running frozen series**. Integrate after all56 cases.
The existing document image supplies Matplotlib/DejaVu; no new package is needed.

After final per-run exports and `analyze_urban_study.py` aggregation:

```bash
python3 scripts/product/plot_urban_study.py \
 --freeze runs/urban-ns3-20261028/freeze.json \
 --aggregate FINAL_AGGREGATE/urban_study.json \
 --analysis-root runs/urban-ns3-20261028/analysis \
 --runs-root runs/native-radio-realtime --output FINAL_FIGURES
```

Heavy rendering belongs to the integration owner after native activity finishes,
under `/tmp/bas-paper-runtime.lock`, using the existing document image. This
command does not start BAS or alter raw. Each produced figure has PNG at320dpi
(width≥1642px), SVG/PDF, data/provenance JSON and RU/EN captions in
`figure_manifest.json`. Only actually rendered files are listed as measured.
`--allow-incomplete` is an explicit preview flag; manifest.preview must stay
false for final manuscript use. The default refuses an unfinished batch.

All four canvases have physical width13.9cm, matching manuscript insertion.
Main text is8pt and annotations/ticks≥7.5pt at that width; no11in source is
shrunk to half size. Saving retains the exact physical canvas rather than
expanding a tight bounding box. Shared legends, short labels and wrapped
footer estimates reduce panel crowding. Final rendered files still require
visual inspection; syntax/structure tests do not prove the absence of overlap.

The geometry pair is selected from the first frozen main block, independent of
success or presence of later files. Failed/missing cases cannot be substituted.
Trajectory stale/source/session gaps are disconnected. Dashed requested altitude
is last-known GCS goal intent carried to window end, not an interpolated physical
measurement or assumed UART/autopilot target feedback. A pre-window initial
intent is used only when an actual recorded ENU goal establishes it.
The XY view marks the configured GCS and building heights. A dotted segment is
the XY projection of the first actual NLOS3D link from the native sampler; the
projection itself does not define the LOS/NLOS classification.

Main pair CI and four-case interaction are read from the stored aggregate.
Missing outcomes remain absent, with explicit counts; failed observed attempts
use crosses. Sensitivity n3/boundary n1 are descriptive. RTF/lag and monitored
process CPU/RSS retain their own units and incomplete coverage; no GPU value is
imputed. Native PHY packet proof stays separate from application event lanes.

Chronology uses observed host-monotonic fields only; ns-3 PCAP timestamps are not
mixed into the axis. The protocol row zooms seconds after actual NLOS; selected
goal and speed rows retain the full window in host seconds after start. Numeric
labels are not piled onto nearly simultaneous CID events; exact timestamps are
retained in data JSON. `follower_receive` is application receipt. Selected new-goal
creation/first successful refresh/UART/completion are different event lanes;
actual speed comes from trajectory samples, not ACK or commanded speed. Critical
UART is chosen from the exact common all-five CID set and its stage-CSV write
ends; independent per-UAV first admissions may belong to earlier epochs and are
never substituted into that common relay/epoch chronology.

Existing exports supply required XY/Z, geometry, stages, new-goal and resources.
Raw coordination logs are needed for timeout/selection/valid_from and endpoint
activation. Without these logs those events cannot be reconstructed from the
summary; missing input files are listed. GPU costs and full-matrix native PHY
loss are not present in these exports and are not produced by this renderer.
